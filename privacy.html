Privacy Policy

LifeTracker · Last updated October 26, 2026

LifeTracker is a personal macOS app used by its developer, with an optional web version at ben1022.github.io/lifetracker-site/app/. This policy explains what data they access and how that data is handled.

Data LifeTracker accesses

  • Google Calendar (read-only): event titles, times, locations and calendar names.
  • Gmail (read-only): the sender, subject, short preview and date of unread messages. LifeTracker never sends, deletes or changes email.
  • Google account email address: to show which account is connected.
  • Google Drive, LifeTracker's own app folder only (drive.appdata): a hidden folder that only LifeTracker can see. LifeTracker cannot see or change any other file in your Drive.

How the data is used

The data is shown on the user's own dashboard and used to write a daily briefing and answer questions about the user's day. It is not used for advertising, sold, or used to build profiles.

Where the data is stored

Calendar and email data is stored only on the user's Mac. Google sign-in tokens are kept in the macOS Keychain. LifeTracker has no servers and collects no analytics.

Sync with Google Drive (optional, off by default). When it is turned on in the Mac app, LifeTracker keeps one file in the hidden app folder of the user's own Google Drive so the web version shows the same things. The file holds tasks and task lists, notes, events added by hand in LifeTracker, muted-event rules, how unread emails were sorted (a category and a one-line summary, keyed by Gmail message ID, not the emails themselves), the last two weeks of daily briefings, and display settings (name, accent color). Deleted items are remembered for 30 days so the deletion reaches every device.

The web version runs entirely in the browser. It signs in with Google, reads Google Calendar, Gmail and the sync file directly from Google, and keeps everything in memory only: nothing is saved in the browser, and closing the tab forgets it. The sign-in token is never stored and is revoked on sign-out. The page loads no analytics or third-party scripts other than Google's sign-in.

Sharing

To write the briefing and answer questions, a summary of the day (event titles and times, task titles, and unread email senders, subjects and previews) is sent to Anthropic's Claude through the user's own Claude account. Anthropic processes it under its own privacy policy. No data is shared with anyone else.

Google API Services User Data Policy

LifeTracker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time from LifeTracker's Settings → Accounts or at myaccount.google.com/permissions. Deleting the app's data folder (~/Library/Application Support/LifeTracker) removes all data stored on the Mac. The sync file can be removed in Google Drive under Settings → Manage apps → LifeTracker → Delete hidden app data.

Contact
